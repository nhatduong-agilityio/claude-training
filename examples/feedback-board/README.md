# Feedback board (Day 11 training app)

A small, dependency-free web app (HTML, CSS, JavaScript; data in `localStorage`) for practising browser testing from a
Claude Code session: console logs, form fill, and an edit → reload → check loop.

Run it from the repo root:

```bash
python3 -m http.server 8011 -d examples/feedback-board
```

Then open <http://localhost:8011>.

It shipped with planted issues (simulated) for the Day 11 browser test; see `docs/day-11-report.md`.
